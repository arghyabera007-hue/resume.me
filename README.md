# resume.me

A modern, responsive personal developer portfolio and resume web application built with React and Vite.

## Features

- **Hero & Profile Section**: Personal introduction and quick actions
- **About Me**: Professional summary and highlights
- **Skills Matrix**: Categorized tech stack and expertise
- **Projects Showcase**: Highlighted projects with live links and tech tags
- **Experience & Education Timeline**: Career progression and achievements
- **Contact Form**: Direct message and social links

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Modern CSS with CSS custom properties and responsive layouts

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/arghyabera007-hue/resume.me.git
   cd resume.me
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
